# Odyss Design References

This folder contains approved visual references for Odyss. They communicate composition, mood, density, identity, and screen-level direction; they are not pixel-perfect specifications. [The Product Spec](../PRODUCT_SPEC.md) overrides any unsupported feature shown in a screenshot.

## References

- [`logo-dark-reference.jpg`](logo-dark-reference.jpg): authoritative identity reference for the Odyss symbol and wordmark. It is a JPEG reference, not a production-ready logo asset.
- [`dashboard-light-v1.jpg`](dashboard-light-v1.jpg): light-theme direction for Dashboard hierarchy, modular panels, statistics, activity, and favorites.
- [`dashboard-dark-v1.jpg`](dashboard-dark-v1.jpg): dark-theme counterpart demonstrating the same Dashboard composition and semantic colors.
- [`library-light-v1.jpg`](library-light-v1.jpg): light-theme direction for Library navigation, controls, filtering, layouts, and tabular rows.
- [`library-dark-v1.jpg`](library-dark-v1.jpg): dark-theme counterpart demonstrating shared Library structure and hierarchy.
- [`add-to-library-dark-v1.jpg`](add-to-library-dark-v1.jpg): direction for search results, selected-media details, and Add to Library workflows.
- [`series-detail-dark-v1.jpg`](series-detail-dark-v1.jpg): direction for series identity, tracking controls, progress, details, seasons, and episodes.

A standalone light-logo reference is unnecessary at this stage because light- and dark-theme wordmark treatment is defined in [the Design System](../DESIGN_SYSTEM.md). Production still requires clean transparent SVG and PNG logo exports.

The missing social-avatar reference is optional. Sample avatars and users are not identity requirements, and social features are outside v1.

Screenshot-only features—including unsupported navigation, People search, and actor favorites—must not be treated as approved scope.
